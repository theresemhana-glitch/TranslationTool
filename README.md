# CodeAlpha_TranslationTool

Language Translation Tool built for the CodeAlpha AI Internship (Task 1).

## Features
- Enter text and choose source and target languages
- Translation using MyMemory (via deep-translator)
- Copy button for the translated text
- Text-to-speech (gTTS) to listen to the translation

## Tech Stack
Python, Streamlit, deep-translator, gTTS

## How to Run
1. Clone the repository
2. Create and activate a virtual environment
3. Install the requirements: `pip install -r requirements.txt`
4. Run the app: `streamlit run app.py`
